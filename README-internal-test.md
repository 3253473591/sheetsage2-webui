> **这是公测包，欢迎传、欢迎提 bug；但别商用。** SheetSage2 的权重是 **CC BY-NC 4.0（非商业）**，
> 随包的 TIFA 对齐器是 **CC BY-NC-SA 4.0**（模型文件；来源与许可见

一句话：**丢一首歌进去，自动扒出旋律 + 识别歌词，然后导出 Synthesizer V 工程（带变速和歌词）。**

## 0. beta1 改了什么（相对 alpha 4）

**一句话：日语能用了、歌词边跑边出、进度不会再"看着像卡死"，而且**第一次装完之后完全离线可用**。**

- **日语**：界面里选「日语」会自动走 Qwen 对齐器；**没装那份权重就当场停下**并告诉你去 `02_models.bat` 选 2，不会给你一套没时间的歌词；
- **歌词边识别边出字**：以前要等全曲跑完才有字，现在每段识别完就出一段（TIFA 本来就是按段对齐的，结果不变）；
- **进度兜底**：SSE 断线（合盖、换网、代理重启）不会再冻在上一帧——运行中有一条 3 秒一次的轮询兜底；
- **停止有反馈**：点了「停止」立刻显示「正在停止…」，等当前这一段跑完才落「已停止」；
- **离线可用**：HuggingFace 的模块缓存钉在包内 `.cache/`，MERT 骨架走本地权重——拔网线也能扒谱；
- **安装器**：pip 失败不再被静默吞掉（以前会装出半个环境，启动时才报 `No module named`）；torch/依赖失败会直接告诉你重跑哪一步；
- **首次运行四个选项**：`00_start.bat` 只启动、`01_install.bat` 装环境（选 1/2/3/4）、`02_models.bat` 以后补模型；
- **界面去噪**：去掉「自检 21/21 · 通过」这类徽标，加载提示不再写「约 30s」这种说明书式括号。

### 已知限制（别当 bug 报）

- **编辑页还没做**：钢琴卷帘只能看不能改（有意推迟）；
- **日语不支持转写成罗马音**（模型能力限制）；
- **`.wv` / `.ape`** 解不了（随包的裁剪版 ffmpeg）；
- 模型权重是 **CC BY-NC 4.0（非商业）**，TIFA 是 **CC BY-NC-SA 4.0**。

## 0.1 alpha 4 改了什么（相对 alpha 3）

**一句话：把「逐字对齐」换掉了，中/粤/英每个字都能落到音上；顺带首次下载少了 1.7 GB。**

### ① 逐字对齐器换成 TIFA（随包带，不用下载）

以前用 Qwen3-ForcedAligner-0.6B，它对**短促/弱唱的字给不出时长**（实测 13~17% 的字是
零长度），还有「一个字被给了 4 秒、后面七八个字挤在它末尾」的塌方。这类错后处理救不回来。

现在换成 [openvpi/TIFA](https://github.com/openvpi/TIFA)：**40M 参数（fp16 后 76MB）**，
按帧解码、每个词必占一段。同一套音符、同一个填词算法下：

| | 以前（Qwen） | 现在（TIFA） |
|---|---|---|
| 《爱情转移》挂对率 | 89.4% | **99.8%** |
| 零宽度字 | 70 / 539（13%） | **0** |
| 挂在音外面的字 | 55 | **0** |

中文、粤语、英语都能用。**日语暂时还走 Qwen 对齐器**（TIFA 1.0 没有日语的离线 G2P），
所以唱日语歌要在 `02_models.bat` 里选 2 单独下它。

### ② 首次下载从 6.0 GB 降到 4.3 GB

对齐器已经随包带了，所以最小集里**不再包含** Qwen 对齐器（1.7 GB）：

| 档位 | 以前 | 现在 |
|---|---|---|
| 最小集（默认） | 6.0 GB | **4.3 GB** |
| +1.7B 识别模型 | +4.5 GB | +4.5 GB |
| +日语对齐器（`02_models.bat` 选 2） | 不需要（本来就有） | **+1.7 GB** |

### ③ 英文歌词的两个老毛病修了

- **行内不加空格**：以前导出的英文行是 `Thereoncewasashipthat`，现在是 `There once was a ship`；
- **续音标记含糊**：以前英文所有延续音都写 `+`、导出再压成 `-`。现在按人工修过的工程
  （`samples/对齐/Fall Out Boy - The Phoenix（人工）.svp`）的写法区分开了：
  **`-` = 延长当前音节，`+` = 同一个词的下一个音节**（`grandfather ++`、`captain +`、`Forty -+`）。
  英文识别结果里的小写和标点（`sea,`）也一并收拾了。

### ④ 两处「少丢字」

- **切片边界让位给人声**：以前 `structure.lab` 的前奏/尾奏边界会切进正在唱的人声里
  （《爱情转移》第一句「徘徊过多少」整句没进识别范围），现在边界只在挨着被跳过段落的
  那一侧往外让；
- **零长度字插值**：对齐器给不出时间的字，按前后两个字之间的空档均分，不再全堆在一个瞬间。

### 版本与老工程

| 改动 | 生效方式 |
|---|---|
| ① 换对齐器 / ③ 英文标记 | **重新跑一次歌词**（「重新识别」） |
| ② 下载体积 | 只影响新装（老包里的对齐器留着也无害） |
| ④ 切片让位 / 插值 | 重新跑歌词 |

**没变的**：扒谱、量化、八度校正、SVP 导出流程、操作方式都与 alpha 3 一样。
**仍然没做**：钢琴卷帘编辑（只能看、不能改音符）。

## 0.1 alpha 3 改了什么（相对 alpha 2）

**两件事，一件在音高、一件在歌词导出。**

### ① 音高：多了一层「局部八度」修正（要在跑歌时生效）

模型出来的旋律不只是"整体高一个八度"（这个早就整体 −12 修掉了），
**同一段旋律在歌里出现多次时，它可能给不同的八度**——比如副歌在歌里出现三次，
机扒给 66 / 54 / 66，第二次整整低了一个八度。

alpha 3 按一条自己能验证的不变量修它：**同一段旋律重复出现，音高只允许差 0**。
挑"改动音符最少"的那种改法；两个候选一样多（分不清哪次是错的）就**不动手**。

实测（13 个真实工程）：**11 个一个音都不动**，动的只有《我本将心向明月》（82 个音）
和《皮囊》（9 个音）——《我本将心向明月》那首和人工修过的版本比，
逐音一致率从 **292/372（79%）升到 361/372（97%）**。

> 想关掉它：`00_start.bat --no-octave-fix`（或 `01_install.bat` 同参数）。默认开。

### ② 歌词导出：没分到字的音**不再唱"啦"**

以前导出的 SVP 里，没分到字的音一律填占位音节『啦』——一首歌里能有几十个，
唱出来是一串"啦啦啦"。**但那些音多数本来就是同一个字的延续**（SheetSage2 多扒/少扒
音符、或者逐字时间戳没给到那里），人工在 Synthesizer V 里修过的版本**一个『啦』都没有**。

现在：没分到字的音，只要前面还有字可续（间隔不超过半拍），就写成**延音**；
只有"前面真的没有字"（句首、长休止之后）才用占位音节。

实测同一首歌：占位音节 **57 → 1**，延音 35 → 91。

> **这一条是下载 SVP 时才算的**：`output/` 里的老工程**不用重扒**，
> 重新点一次下载 SVP 就是新结果（`EXPORT_REVISION` 已经变了，老缓存自动作废）。

### 版本与老工程（alpha 3 当时的口径）

| 改动 | 生效方式 |
|---|---|
| ① 局部八度修正 | **跑歌时**（扒谱阶段）→ alpha 2 跑过的老工程**要重扒**才有 |
| ② 歌词延音 | **下载 SVP 时** → **不用重扒**，重新下载即可 |

**没变的**：音频转写、歌词识别、量化口径、SVP 导出流程都与 alpha 2 一样，
操作方式不用重新学。**仍然没做**：钢琴卷帘编辑（只能看、不能改音符）。

## 1. 怎么开始（三步，不用敲命令）

包里就三个双击入口，**照顺序用就行**：

| 文件 | 什么时候双击 |
|---|---|
| `01_install.bat` | 第一次：准备环境 + 下模型（会问你选 1-4） |
| `00_start.bat` | 以后每次启动 |
| `02_models.bat` | 以后想补模型（日语 / 更高精度） |

1. **解压**到一个**路径里只有英文和数字**、而且**空间够**的目录（比如 `D:\SS2`）。
   - 包是 **`.7z`**：Win11 24H2 起资源管理器原生能开，老系统装个 [7-Zip](https://www.7-zip.org/) 就行。
   - 需要 **20 GB 以上可用空间**：模型 4.3 GB（最小集）+ torch 1.8 GB + 产物。
   - 别放在 C 盘根目录或带中文/空格的路径下，出问题不好查。
2. **双击 `01_install.bat`**，按提示选一个档位（见 §2）。
   - 进度就在窗口里，**看着就行**；中途断了/关掉了，**再双击一次**，已经下完的不会重下。
   - 只想先看看界面：选 **4**，什么都不下。
3. 装完双击 **`00_start.bat`**：起服务并打开浏览器（地址一般是 `http://127.0.0.1:8000`）。
   把 mp3 / flac 拖进页面 → 选参数 → 点「开始扒谱」→ 跑完点「开始识别歌词」→ 下载 SVP。

> 想只体检不下东西：`01_install.bat --check`
> 想补下更准的识别模型：双击 `02_models.bat`，选 3
> 选了 4（暂不下载）也没关系：`00_start.bat` 会提醒你"模型还没下"，仍然能进去看界面。

### 怎么看"它还在动"

下载时**一直有进度**，不会让你干等：

```
    model.safetensors:  42.1%  767.9 MB/1.7 GB  9.8 MB/s  剩 1m35s  [3/13 · 总 2.6/4.3 GB]
```

- 一行原地刷新（不会刷屏），有 **百分比 / 已下 / 总量 / 速度 / 剩余时间**；
- 末尾那个 `[3/13 · 总 2.6/4.3 GB]` 是**整体进度**：第几个文件、三个仓库合起来下了多少；
- **校验 sha256 的时候也会说一声**（大文件要算几秒，那几秒没进度是正常的）；
- **超过 20 秒没收到数据**会主动提示"网络卡住？Ctrl+C 后重跑，已下的部分会接着下"；
- 建 `.venv`、`import torch` 这类"本来就没输出"的步骤，脚本会先说明要等多久。

## 2. 首次运行会下什么

| 内容 | 大小 | 说明 |
|---|---|---|
| 便携 Python + ffmpeg | 已在包里 | **你不用装 Python，也不用装 ffmpeg** |
| TIFA 对齐器（40M） | **已在包里** | 中文 / 粤语 / 英语的逐字对齐用它，**不用额外下载对齐器** |
| torch + torchaudio（cu130） | 1.8 GB | 从南京大学 PyTorch 镜像下，带 sha256 校验、断了能续 |
| 项目依赖（transformers 等） | 几百 MB | 走清华 PyPI 镜像 |
| **模型最小集**（默认） | **4.3 GB** | SheetSage2（扒谱） + MERT-v2（伴奏/和弦） + Qwen3-ASR-**0.6B**（出字） |
| Qwen3-ASR-**1.7B**（**可选**） | +4.5 GB | 专有名词/生僻词更准（布达拉宫、喜马拉雅山…）。**不下也能用** |
| Qwen3-ForcedAligner（**只有日语要**） | +1.7 GB | TIFA 1.0 没有日语的离线 G2P，唱日语歌才需要它（`02_models.bat` 选 2） |

**首次运行会问一次「要下载哪一套」**（不写模型名，按用途选就行）：

```
  这次要下载哪一套？（说明见 README）
    1  默认（中/粤/英）                  约 4.3 GB  —— 默认
    2  日语特供                                +1.7 GB
    3  提高歌词识别精度（适合大显存）          +4.5 GB
    4  暂不下载（下次启动还会再问）
  选一个 1/2/3/4（回车 = 1）:
```

- **1 默认**：中文 / 粤语 / 英语直接能用，逐字对齐由**随包自带的 TIFA** 负责，不用再下对齐器；
- **2 日语特供**：额外下日语要用的那份对齐权重（TIFA 没有日语的离线 G2P）；
- **3 提高歌词识别精度**：换更大的识别模型，专有名词/生僻词更准（布达拉宫、喜马拉雅山…），显存吃紧就别选；
- **4 暂不下载**：只想先看看界面。**下次启动 `00_start.bat` 会再问一次这四个选项**，不会悄悄带着空模型启动。

选过 1/2/3 之后就不会再问；以后想补，双击 `02_models.bat`：选 3 是精度，选 2 是日语。

## 3. 显卡与速度

- **有 NVIDIA 卡 + 较新驱动**：全曲扒谱一首 3~4 分钟的歌大约 1~3 分钟（10G 卡实测）。
  - cu130 轮子要 **CUDA 13 一代的驱动**（本机实测 591.86 / CUDA 13.1）。驱动太旧会装上了也用不了 CUDA。
- **没有 N 卡 / 驱动太旧**：能跑，但**会很慢**（全曲扒谱几分钟到十几分钟，歌词更慢）。
  首次运行的自检会直接告诉你 CUDA 能不能用。
- 显存小的卡（4G）：双击后选**模式 2**（4G 特供），服务端会把显存预算和参数一起定死。

## 4. 出问题了怎么办

| 现象 | 处理 |
|---|---|
| 下载断了 / 关掉了窗口 | 再双击 `01_install.bat`（断点续传）：**已下完的文件会跳过**，从断的地方继续 |
| 报错说某个文件 sha256 不对 | 重跑一次；还不行就把 `wheels/` 或 `models/` 里那个文件删掉再重跑 |
| 自检说 CUDA 不可用 | 多半是显卡驱动太旧。先按 CPU 跑（慢），或者升级驱动 |
| 端口被占（会提示自动换端口） | 不用管，看窗口里打印的地址；想固定就 `00_start.bat 8010` |
| 上传报「格式不支持」 | 支持 mp3 / wav / flac / m4a / aac / ogg / opus / wma / aiff / mp4 等；`.wv`（WavPack）和 `.ape` 这三种**随包的裁剪版 ffmpeg 解不了**，先转成 wav/mp3 再传 |
| 扒出来的谱听着一开始就不对 | 旋律默认**降一个八度**（模型输出整体高一个八度，和弦是对的），另外 alpha 3 会把"同一段旋律重复出现却差一个八度"的地方拉齐；两件都**想自己手动改**就加 `--no-octave-fix` |
| 导出的 SVP 里有几处听着像"啦" | 那几处是**前面真的没有字可续**（句首 / 长休止之后，识别也没给字）。其余没分到字的地方现在都是延音 |
| 想反馈 bug | 点顶栏「诊断包」，把压缩包 + 窗口里的报错 + 那首歌的**歌名**发给任意 AI（或贴到反馈里） |

排障用的两件事：`01_install.bat --check`（环境体检）、`bootstrap-state.json`（上次自检的记录）。

## 6. 已知的坑（先看这里，别当 bug 报）

- **唱日语歌要单独下对齐器**：随包的 TIFA 只覆盖中/粤/英；日语必须用另一份对齐权重，
  而它不在最小集里。下法：双击 `02_models.bat` 选 2（+1.7 GB）。
  **没下就会在识别歌词时直接停下**（不会给你一套没时间的歌词），错误卡会写
  「日文歌要用日语对齐器，但这台机器上还没装」+ 该点哪个文件——补完重跑「识别歌词」即可。
- **英文的 `+` 换含义了**：alpha 4 起 `+` 表示「同一个词的下一个音节」，`-` 才是延长。
  alpha 3 跑过的英文工程要**重新跑一次歌词**，否则老的 `+` 会被当成新音节。
- **卷帘只能看不能改**：钢琴卷帘编辑**这个版本不做**（有意推迟），音符是只读的。
- **SVP 的速度轴**：恒速曲只写一条速度（比如整首 125 就一条 125），播完和原曲可能差 1~3 秒
  —— 这是故意的（时间轴干净、好改），严格对齐原音频要用 `output/<歌>/project.json` 里的逐小节速度表。
- **和弦轨不降八度**：模型的旋律整体高一个八度（已自动降），但和弦轨本来就是准的，不动。
- **个别段落音区可能被"拉齐"**：alpha 3 的局部八度修正只在"同一段旋律重复出现、音高不一致"
  时动手，而且是按多数派；平票（两次出现一样长）宁可不动。**如果某一处你听着不对，
  想自己手动改八度**：`00_start.bat --no-octave-fix` 关掉它即可（其余功能不受影响）。
- **`.wv` / `.ape`**：解不了（见上表）。
- **老工程要用上 alpha 3 得看情况**：
  - **歌词延音**（没字的音不再唱"啦"）：**不用重扒**，重新下载一次 SVP 就行；
  - **音高局部八度修正**：跑歌时才算，alpha 2 跑过的工程**要重扒**才有；
  - 量化口径与 alpha 2 相同，不需要重扒。
- **内测范围**：Windows 10/11 x64 + NVIDIA（可选）。没有 mac/linux 包。
