# SheetSage2 Studio · alpha 1 内测说明

> **这是内测包，别外传、别商用。** SheetSage2 的权重是 **CC BY-NC 4.0（非商业）**，
> 随包的 ffmpeg 也有自己的许可（见 `runtime/ffmpeg/LICENSE-ffmpeg.txt`）。

一句话：**丢一首歌进去，自动扒出旋律 + 识别歌词，然后导出 Synthesizer V 工程（带变速和歌词）。**

---

## 1. 怎么开始（三步，不用敲命令）

1. **解压**到一个**路径里只有英文和数字**、而且**空间够**的目录（比如 `D:\SS2`）。
   - 需要 **20 GB 以上可用空间**：模型 6.0 GB（最小集）+ torch 1.8 GB + 产物。
   - 别放在 C 盘根目录或带中文/空格的路径下，出问题不好查。
2. **双击 `webui.bat`**。
   - 第一次运行会自动准备环境（见 §2），进度就在窗口里，**看着就行**。
   - 中途断了/关掉了：**再双击一次**，已经下完的不会重下。
3. 下完会自动起服务并打开浏览器（地址一般是 `http://127.0.0.1:8000`）。
   把 mp3 / flac 拖进页面 → 选参数 → 点「开始扒谱」→ 跑完点「开始识别歌词」→ 下载 SVP。

> 想只体检不下东西：`setup.bat --check`
> 想补下 1.7B 识别模型：`setup.bat --with-1.7b`

### 怎么看"它还在动"

下载时**一直有进度**，不会让你干等：

```
    model.safetensors:  42.1%  767.9 MB/1.7 GB  9.8 MB/s  剩 1m35s  [3/13 · 总 2.6/6.0 GB]
```

- 一行原地刷新（不会刷屏），有 **百分比 / 已下 / 总量 / 速度 / 剩余时间**；
- 末尾那个 `[3/13 · 总 2.6/6.0 GB]` 是**整体进度**：第几个文件、四个仓库合起来下了多少；
- **校验 sha256 的时候也会说一声**（大文件要算几秒，那几秒没进度是正常的）；
- **超过 20 秒没收到数据**会主动提示"网络卡住？Ctrl+C 后重跑，已下的部分会接着下"；
- 建 `.venv`、`import torch` 这类"本来就没输出"的步骤，脚本会先说明要等多久。

## 2. 首次运行会下什么

| 内容 | 大小 | 说明 |
|---|---|---|
| 便携 Python + ffmpeg | 已在包里 | **你不用装 Python，也不用装 ffmpeg** |
| torch + torchaudio（cu130） | 1.8 GB | 从南京大学 PyTorch 镜像下，带 sha256 校验、断了能续 |
| 项目依赖（transformers 等） | 几百 MB | 走清华 PyPI 镜像 |
| **模型最小集**（默认） | **6.0 GB** | SheetSage2（扒谱） + MERT-v2（伴奏/和弦） + Qwen3-ASR-**0.6B**（歌词） + ForcedAligner（逐字对齐） |
| Qwen3-ASR-**1.7B**（**可选**） | +4.5 GB | 专有名词/生僻词更准（布达拉宫、喜马拉雅山…）。**不下也能用** |

**要不要 1.7B？** 首次运行会问一次：

```
  模型档位（1.7B 识别模型是**可选项**）：
    1  最小集：SheetSage2 + MERT + 0.6B 识别 + 对齐器  约 6.0 GB  —— 默认
    2  全量：再加 1.7B 识别模型（专有名词更准）        +4.5 GB
    3  先不下模型（只想看界面）
  选一个 1/2/3（回车 = 1）:
```

先选 1 也行，**以后随时补**（`setup.bat --with-1.7b`，或者 `setup.bat` 选 2）。

## 3. 显卡与速度

- **有 NVIDIA 卡 + 较新驱动**：全曲扒谱一首 3~4 分钟的歌大约 1~3 分钟（10G 卡实测）。
  - cu130 轮子要 **CUDA 13 一代的驱动**（本机实测 591.86 / CUDA 13.1）。驱动太旧会装上了也用不了 CUDA。
- **没有 N 卡 / 驱动太旧**：能跑，但**会很慢**（全曲扒谱几分钟到十几分钟，歌词更慢）。
  首次运行的自检会直接告诉你 CUDA 能不能用。
- 显存小的卡（4G）：双击后选**模式 2**（4G 特供），服务端会把显存预算和参数一起定死。

## 4. 出问题了怎么办

| 现象 | 处理 |
|---|---|
| 下载断了 / 关掉了窗口 | 再双击 `webui.bat`（或 `setup.bat`）：**已下完的文件会跳过**，从断的地方继续 |
| 报错说某个文件 sha256 不对 | 重跑一次；还不行就把 `wheels/` 或 `models/` 里那个文件删掉再重跑 |
| 自检说 CUDA 不可用 | 多半是显卡驱动太旧。先按 CPU 跑（慢），或者升级驱动 |
| 端口被占（会提示自动换端口） | 不用管，看窗口里打印的地址；想固定就 `webui.bat 8010` |
| 上传报「格式不支持」 | 支持 mp3 / wav / flac / m4a / aac / ogg / opus / wma / aiff / mp4 等；`.wv`（WavPack）和 `.ape` 这三种**随包的裁剪版 ffmpeg 解不了**，先转成 wav/mp3 再传 |
| 扒出来的谱听着一开始就不对 | 旋律默认**降一个八度**（模型输出整体高一个八度，和弦是对的）。觉得不对可以提，但一般不用改 |
| 想反馈 bug | 把 **`bootstrap-state.json`** + 窗口里的报错 + 那首歌的**歌名**发我 |

排障用的两件事：`setup.bat --check`（环境体检）、`bootstrap-state.json`（上次自检的记录）。

## 5. 包里都有什么

```
webui.bat          双击这个（首次运行会先准备环境）
setup.bat          只准备/修复环境（--check 只体检，--with-1.7b 补下 1.7B）
内测说明.md        本文件
downloads.json     下载清单（torch / 模型的直链与 sha256）
bootstrap-state.json  上次自检的记录（首次运行后生成）
runtime\python\    便携 CPython 3.12（包里自带，不用装）
runtime\ffmpeg\    裁剪版静态 ffmpeg 7.1.1（扒谱/波形/切片都靠它）
src\ scripts\ tools\  程序本体
web\               前端（已构建好，不需要 Node）
models\            模型下到这里（首次运行填）
output\            每次跑歌的产物
wheels\            下载的 torch 轮子（留着，重装时不用再下）
```

## 6. alpha 1 已知的坑（先看这里，别当 bug 报）

- **SVP 的速度轴**：恒速曲只写一条速度（比如整首 125 就一条 125），播完和原曲可能差 1~3 秒
  —— 这是故意的（时间轴干净、好改），严格对齐原音频要用 `output/<歌>/project.json` 里的逐小节速度表。
- **和弦轨不降八度**：模型的旋律整体高一个八度（已自动降），但和弦轨本来就是准的，不动。
- **`.wv` / `.ape`**：解不了（见上表）。
- **内测范围**：Windows 10/11 x64 + NVIDIA（可选）。没有 mac/linux 包。
